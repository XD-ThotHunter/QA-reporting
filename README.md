# RE Project — Bug Reports

This repository is the **only place to submit bug reports** for the RE project.  
Source code is maintained separately and is not visible here.

## How to submit a bug

1. Click **[New Issue](../../issues/new/choose)**
2. Select **Bug Report**
3. Fill in all required fields
4. Submit — the team will triage and respond

## Guidelines

- One bug per issue
- Include steps to reproduce every time
- Attach screenshots or logs where possible
- Do **not** include passwords, private keys, or personal data in reports

## Severity guide

| Level | Examples |
|---|---|
| Critical | App crash, funds at risk, data loss |
| High | Feature completely broken, login failure |
| Medium | Feature partially broken, wrong output |
| Low | UI glitch, typo, cosmetic issue |
